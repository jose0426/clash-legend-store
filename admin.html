Activa la subida de tus bases

La conexión del proyecto ya está guardada. Completa estos dos pasos en Supabase para habilitar el acceso y guardar tus diseños:

  1. Abre tu proyecto Supabase, entra a SQL Editor → New query, copia todo el archivo supabase/setup.sql de esta carpeta, pégalo y pulsa Run. El correo de administración ya está puesto en el SQL.
  2. En Supabase, ve a Authentication → Users → Add user y crea el usuario josegood222@gmail.com. Define tú la contraseña ahí; no la compartas aquí.
  3. Vuelve a esta página, inicia sesión con ese correo y la contraseña que creaste. Entonces aparecerá el formulario para subir tus imágenes, enlaces y precios.

La URL y clave pública ya están configuradas. No compartas contraseñas ni claves privadas de Supabase. Guía completa: README del proyecto.
